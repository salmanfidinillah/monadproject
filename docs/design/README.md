## Arah visual

Party game, navy gelap, bom oranye/kuning, pemain biru/ungu, kartu membulat, timer serta tombol besar, teks Indonesia, kontras jelas. Holder ditandai ikon dan teks. Gunakan layer yang dapat diedit dan layout responsif; jangan mengganti hasil Figma dengan gambar rata. Tidak perlu ilustrasi 3D/desain sistem besar.

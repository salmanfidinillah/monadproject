# BOM OPER video explainer

[Watch or download the English explainer (about 30 seconds, 1280×720)](BOM-OPER-Monad-Explainer.webm).

The video introduces BOM OPER, explains the pass and hot-pass rules, and describes Monad as an EVM-compatible Layer 1 designed for parallel execution. It shows how the game uses Monad Testnet, then states that public transaction proof for a full two-player round is still pending.

Arena and results imagery comes from the Figma design concepts and is labeled in the video. This is a motion explainer, not footage of a completed on-chain multiplayer round.
